📧 Smart Email Assistant
Smart Email Assistant is an intelligent application built with Spring Boot and Spring AI, designed to generate AI-powered email replies directly within Gmail, using the Gemini API.

🔧 Technologies Used
Java 17+

Spring Boot

Spring AI (integrated with Gemini)

Gmail API

Google Chrome Extension (JavaScript/HTML/CSS)

REST API

JSON

Gemini (Google’s LLM)

🎯 Key Features
📩 Automatic analysis of incoming emails and generation of personalized replies using AI.

🔘 Customizable reply modes: the user can choose the tone or style of the response (e.g., formal, friendly, concise).

🌐 Gmail Chrome Extension: allows users to generate and send AI-based replies directly from the Gmail interface.

🔄 Real-time communication between the Chrome extension and the Spring Boot backend via REST APIs.

💡 Project Goal
The goal of this project is to improve productivity for users who manage a large number of emails, by providing fast, coherent, and context-aware responses generated by artificial intelligence.

🧩 Chrome Extension
The Chrome extension integrates into the Gmail interface and adds a dedicated button to automatically generate replies. It sends the email content to the Spring Boot backend, which uses the Gemini model to build a relevant response.
